# AGENTS.md

## Project Layout

- **App code:** `taskmanager/` — all SvelteKit source lives here. Run commands from this directory.
- **Specs and plans:** `CONTEXT.md`, `SPEC.md`, `docs/superpowers/plans/` — design docs, not code.

## Commands (run in `taskmanager/`)

| Command | Purpose |
|---------|---------|
| `npm run dev` | Start dev server (localhost:5173) |
| `npm run check` | Type-check (runs `svelte-kit sync` first) |
| `npm run lint` | Prettier check |
| `npm run format` | Prettier write |
| `npm run db:push` | Push schema to SQLite |
| `npm run db:generate` | Generate migration files |
| `npm run db:migrate` | Run pending migrations |

**Order when verifying changes:** `lint` → `check`. There are no tests yet.

## Environment

- `DATABASE_URL` **must** be set (required by `drizzle.config.ts` and `src/lib/server/db/index.ts`).
- Default DB path: `./data/data.sqlite` (see plan). The `.gitignore` excludes `*.db` but not `*.sqlite` — be careful.

## Tech Stack Quirks

- **Svelte 5 runes mode** is forced in `svelte.config.js` (`runes: true` for all non-node_modules files). Use `$state`, `$derived`, `$effect`, `$props()` — not Svelte 4 store/component patterns.
- **Tailwind v4** via `@tailwindcss/vite` plugin. No `tailwind.config.js` — use CSS-first configuration. The stylesheet is `src/routes/layout.css` with just `@import 'tailwindcss'`.
- **Prettier:** tabs, single quotes, `trailingComma: "none"`, `printWidth: 100`. Plugins: `prettier-plugin-svelte`, `prettier-plugin-tailwindcss`. Config in `.prettierrc`.
- **Drizzle schema** is at `src/lib/server/db/schema.ts`. Note the `server/` prefix — SvelteKit loads-only convention.
- **tsconfig** extends `./.svelte-kit/tsconfig.json` (generated by `svelte-kit sync`). Run `svelte-kit sync` if TypeScript can't resolve `$lib` or `.$types`.

## Current State

Early scaffold. The DB schema has only a minimal `task` table (`id` UUID, `title`, `priority`). No auth, no routes beyond the welcome page, no components. The full MVP plan is in `docs/superpowers/plans/2026-06-01-task-manager-v2-mvp.md` — follow it for implementation order.

## Design Decisions (from `CONTEXT.md`)

- **Single user, no multi-tenant.** First-run setup creates the account. No sign-out button.
- **Auto-create on blur.** Task persists when the title field loses focus — no Save button.
- **Query-time filtering.** Completed tasks >7 days old are hidden from queries, not deleted.
- **Auto-sort.** priority → due date → created date. No drag-and-drop.
- **Due date prompt** appears when the slide-over closes, not during capture.
- **Keyboard shortcuts** are first-class. See `CONTEXT.md` for the full list.

## Dependencies Not Yet Installed
